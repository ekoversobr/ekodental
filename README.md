## Antes de publicar
1. Confirme se o número e o endereço estão corretos.
2. Revise os serviços efetivamente oferecidos e as informações profissionais.
3. O formulário não salva dados em um banco: ele abre o WhatsApp com uma mensagem pré-preenchida. A pessoa ainda precisa revisar e enviar.
4. Este pacote ainda não inclui tags do Google Ads, Google Tag Manager ou Google Analytics.
5. Configure e teste as conversões separadamente antes de lançar campanhas.
6. Não inclua informações clínicas sensíveis no formulário.
7. Verifique as normas vigentes de publicidade odontológica e privacidade antes da publicação.

## Como testar
Abra `index.html` em um navegador moderno. Teste os links do WhatsApp em celular e computador.

## Publicação
O site pode ser hospedado em qualquer serviço de arquivos estáticos, incluindo GitHub Pages. A publicação no GitHub Pages precisa ser ativada nas configurações do repositório.
